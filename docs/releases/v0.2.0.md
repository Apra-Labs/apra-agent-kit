## What's new

### Scheduled Workflows

Run any registered workflow on a cron schedule. Config-driven, timezone-aware,
with queue/skip overlap policies.

```js
// host.config.mjs
modules: {
  scheduler: {
    enabled: true,
    schedules: [
      {
        name: 'morning-briefing',
        workflow: 'hello',
        args: {},
        cron: '0 9 * * *',
        timezone: 'Asia/Kolkata',
        overlap: 'skip',
      },
    ],
  },
}
```

Two backends:
- **VM (in-process)**: uses [croner](https://github.com/Hexagon/croner) timers
- **Azure Functions (durable)**: registers one Azure Timer Trigger per schedule

Scheduled runs create normal jobs — they appear in `GET /jobs/:id`, stream
events over SSE, and deliver results via webhook. Check schedules at
`GET /schedules`.

### Docker Deployment Modes

Two separate docker-compose files ship with every scaffolded project:

| File | Mode | Chat URL |
|---|---|---|
| `docker-compose.yml` | VM (Express + SQLite) | `localhost:3000/chat` |
| `docker-compose.azure.yml` | Azure Functions (Durable + Azurite) | `localhost:7071/api/chat` |

Start either with a single command — token passed from shell, no `.env` file:

```bash
# VM
CLAUDE_CODE_OAUTH_TOKEN=$(claude setup-token) docker compose up -d --build

# Azure Functions
CLAUDE_CODE_OAUTH_TOKEN=$(claude setup-token) docker compose -f docker-compose.azure.yml up -d --build
```

### Fleet Auth in Docker

Docker containers now provision Fleet OAuth credentials at startup via an
entrypoint script that runs `apra-fleet auth --oauth "$CLAUDE_CODE_OAUTH_TOKEN"`
before the host starts. This fixes the auth failure that occurred because
`~/.claude/.credentials.json` didn't exist in fresh containers.

### Azure Functions Dockerfile Improvements

- Handles missing `package-lock.json` (scaffolded projects don't ship one)
- `patch-config.mjs` transforms the project's own `host.config.mjs` at Docker
  build time (express → azure-functions, sqlite → durable), so no separate
  Azure config file is needed
- Entrypoint provisions Fleet auth from environment variable
