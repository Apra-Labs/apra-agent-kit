# v0.1.0 — First Public Release

**Date:** 2026-09-29
**Package:** `@apralabs/create-agent-kit`
**Install:** `npm create @apralabs/agent-kit my-agent`

---

## Highlights

This is the first public npm release of the Apra Agent Kit — a modular toolkit
for building autonomous AI agents on [Apra Fleet](https://github.com/Apra-Labs/apra-fleet).

### Scaffold in one command

```bash
npm create @apralabs/agent-kit my-agent
cd my-agent
npm run doctor   # check your environment
npm run hello    # run the starter workflow
```

The generator copies the kit framework, writes a starter workflow, and offers to
install Fleet and the Claude CLI. It explains each step before it asks.

### What's included

| Component | Description |
|-----------|-------------|
| **Pool** | Worker pool with roster management, ephemeral scaling, and cleanup |
| **Transport** | stdio-based Fleet transport layer |
| **Host** | HTTP host with strategy-based run loop, budgets, guardrails, and routing |
| **MCP** | Model Context Protocol server with tool registry |
| **Evals** | Eval harness with graders and Markdown report generation |
| **Comm** | Express and Azure Functions adapters |
| **Jobs** | Async job dispatch with in-process and Durable Functions backends |
| **Chat** | Web chat UI with transcript persistence |
| **Memory** | Three-tier memory system (conversation context, run state, long-term FSRS-6) |
| **Agent Builder** | Claude Code skill for guided agent creation |

### CI/CD
